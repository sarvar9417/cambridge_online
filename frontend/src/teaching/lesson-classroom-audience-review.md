# Classroom audience review

This note records the three-lens acceptance criteria for projected lessons.

## Teacher lens
- The teacher must always know the current chapter/topic/page without reopening navigation.
- Long pages must scroll before semantic page navigation happens.
- The current teaching segment should be visually obvious while scrolling.
- Controls should be usable from a keyboard and should not expose source/audit chrome to students.

## Student lens
- Core content must remain legible from the back of a classroom.
- Explanation, worked example, activity, key term, code/table/figure and Past Paper content must have distinct visual grammar.
- Technical corpus/LO/provenance metadata must not compete with the learning task on the projected screen.
- The screen should clearly indicate when more content exists below.

## Designer lens
- Projection must look like an academic teaching surface, not a dashboard enlarged to full screen.
- Avoid excessive nested rounded cards and shadows; use hierarchy, whitespace, dividers and restrained semantic accents.
- Keep line length, contrast and vertical rhythm stable across 16:9 classroom displays.
- The projection layer must be isolated from normal Teacher reading mode and must load last in the CSS cascade.
