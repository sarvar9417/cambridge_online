## READY gate semantics

A paper is reported READY only when all of the following are true for the effective canonical question corpus:

- QP source metadata contains source URL, SHA-256 and page count.
- Corresponding MS source row exists.
- Mark-bearing question-parts exist and sum to the component total.
- Approved mark schemes exist for every marked leaf and sum to the component total.
- Every marked leaf is approved.
- Every marked leaf has `content_version=1` structured content.
- Every marked leaf has a non-empty LaTeX stem and `body_format='latex'`.
- Every marked leaf has a command word.
- Every marked leaf has exactly one primary subtopic.
- Every marked leaf has at least one learning objective.
- No primary subtopic or LO mapping is below the closure confidence threshold.
- Every marked leaf is pinned to the effective source paper ID and source SHA in `content_json.source`.
- No source-bridge wording remains in LaTeX stems.
- No explicit Cambridge/PDF footer extraction artefacts remain.
- No unresolved diagram/image assets remain.
